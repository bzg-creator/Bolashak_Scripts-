# Bolashak_Scripts
Проект решает проблему засорённости справочника стран в корпоративной SQL Server. Одни и те же страны хранились под разными названиями (США, Америка, US) с разными GUID, а часть записей вообще не имела DictionaryId (NULL). Всё это затрудняло фильтрацию и отчётность. Задача привести все записи к единому стандарту:один GUID одно каноническое название
